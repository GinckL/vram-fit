Know your VRAM before you download a single gigabyte.

vram-fit computes the exact GPU memory a local LLM needs — model weights, KV cache, activation buffers, CUDA/driver overhead and LoRA/QLoRA optimizer states — from config.json or the GGUF header alone. It probes your NVIDIA, AMD or Apple Silicon GPU, predicts tokens/s from memory bandwidth, and prints a llama.cpp, Ollama, vLLM, ExLlamaV2 or Unsloth command that will not hit CUDA out of memory.

$ pip install vram-fit
$ vram-fit fit Qwen/Qwen2.5-14B-Instruct --gpu auto -c 32k
Model Weights 8,148 MiB KV Cache 1,632 MiB Activation Buffers 417 MiB CUDA/Driver 300 MiB VRAM ceiling 12 GiB · RTX 4070 · 35.6 tok/s

What it measures

Weights, tensor by tensor

llama.cpp k-quant mixing rules (Q6_K heads, use_more_bits layers), exact GGUF types from remote headers, AWQ/GPTQ scales, EXL2, FP8, NF4, MXFP4.

KV cache

GQA, MQA, DeepSeek MLA, Gemma/gpt-oss sliding windows, hybrid linear layers, q8_0 / q4_0 / fp8 / Q4 cache types.

Activations & overhead

llama.cpp compute buffers with and without flash attention, vLLM profiling peak and CUDA graphs, CUDA/ROCm/Metal context.

Fine-tuning

LoRA/QLoRA/full: adapters, grads, AdamW / 8-bit / paged / Adafactor states, gradient checkpointing incl. Unsloth offload.

Placement & speed

-ngl layer split, --n-cpu-moe expert offload, PCIe spill, decode/prefill tok/s from bandwidth and TFLOPS.

Machine-readable

--json on every command, a JSON Schema, a Python API and a REST + WebSocket server.

Common questions

How do I calculate exact VRAM for LoRA or QLoRA fine-tuning before downloading a model?

vram-fit fit <hf-repo> --mode qlora --engine unsloth -c 4k --gpu auto reports base weights, adapters, gradients, optimizer states and activations, picks the largest micro-batch that fits, and writes train.py.

How do I fix CUDA out of memory in llama.cpp / Ollama at long context?

vram-fit fit <model> -c 32k --gpu auto chooses -ngl, KV-cache quantization and quant so everything fits, and prints the command or Modelfile.

How big is the KV cache?

Σ layers × kv_heads × (head_dim_k·bytes_k + head_dim_v·bytes_v) per token — Llama-3-8B: 128 KiB/token in f16, exactly 1024 MiB at 8k. vram-fit inspect <model> prints it for any architecture.

Which GGUF quant should I download?

vram-fit matrix <gguf-repo> --gpu <your-gpu> shows every quant × context cell as fits / tight / offload / spill / oom with tok/s.
